## About Coverage Tool Demo

Coverage Tool Demo is an HTML-based sample application built for internal team review. It presents a focused coverage experience that can be used to examine how coverage data is displayed, how contractors are selected, and how the heatmap view supports visual review.

This repository is suited to walkthroughs, feedback sessions, and layout validation where a lightweight web demo is more useful than a full production implementation. The current build keeps the scope intentionally narrow so the main interface elements and review flow are easy to inspect.
